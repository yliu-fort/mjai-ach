（`nn_updates.py:261-264` 强制拒绝非 SGD）、value_coef=1.0、entropy_coef=0.01、hedge η=1.0、
l_th=2.0、ratio_eps=0.5、单侧门控、batch=64 样本（`target_samples: 64`）、单 mini-batch 单次

eval_every=1e5、seeds 0–7（`reproduce_paper.py:58`）。

| 参数 | 论文值 | 裸默认值 | 出处 |
|---|---|---|---|
| policy_kind | mlp | `tabular`（ACH-tabular = CFR+ wrapper，非论文 ACH） | experiment.py:50 |
| learning_rate | 1e-3 | 1e-4（注释自标 NN-tuned） | experiment.py:67 |

| 批次/总长口径 | 64 样本 / 1e7 env steps | 整 50 episodes/轮 / 500 轮 round 模式 | experiment.py:52,64,88-89 |

**次要违规**：`configs/games/*.yaml` 未知键被静默忽略（`game_config.py:55`），违反 §9
"unknown keys error loudly"（exp YAML 侧经 `ExperimentConfig(**data)` 是严格的）。

## 四、Q3/Q4 证据摘要

**Q3 阻断点**：`main.py:62-64` 重建 MLP 只传 `obs_size/num_actions/seed`，忽略
`MLP.save()` 专为重建写出的 `policy.pt.meta.json`（mlp.py:200-221）。实测加载
`runs/reproduce/kuhn_ach_mlp_mirror/seed_7/checkpoints/step_154433` → `RuntimeError:
Missing key(s): "torso.2.weight"...`。runs/ 下 2449 个 checkpoint 全为 `(128,)`，全军覆没。

**Q3 次要缺陷**：policy 选择器不按游戏过滤、不校验 `manifest.game`/obs_size 匹配、无分页
（实测一次打印 2449 行）；加载无 try/except，traceback 直接抛给用户。

**Q4 实测发现**：
- ✅ 机制：console script（pyproject.toml:52）、7 游戏 renderer+parser 齐备、19 个 CLI 单测通过、
  auto 对局跑通、坏输入逐条拒绝。
- ✅ 盲输入合规（§4 强制项）：brps / goofspiel5_ii / oshi_zumo 的 parser 提示与
  `match_runner.py:102-116 _simultaneous_step` 逐座位渲染机制均不泄露对手同时选择。
- ❌ TTT renderer 平面语义错误（renderers/ttt.py:20-29）：OpenSpiel plane0=empty，X 在 plane2，
  renderer 从不读取 → 空棋盘显示满盘 X，棋盘不可读。
- ❌ Oshi-Zumo wrestler 位置解析失败兜底显示 `cell -1`（renderers/oshi_zumo.py:56-60）。
- ❌ 菜单 stdin EOF 死循环刷屏（main.py:136-138）；对局中 EOF 抛 traceback（match_runner.py:129）。

- ❌ `rich` 依赖已声明（pyproject.toml:29-30 注释承诺 panels/tables/color）但 cli 零引用：

## 五、修复方案（按优先级；每项独立成 PR，遵守 §10 一个逻辑变更一个 commit）

### P0 — 阻断

**F1. 修复 CLI checkpoint 加载（Q3 核心）**
- 动作：加载链路改为元数据驱动——读取 sidecar `policy.pt.meta.json`（hidden_sizes/activation）
  与 `manifest.json`（game/obs_size/num_actions）重建正确架构；重建逻辑下沉到

  `src/mjai/cli/policy_registry.py`。
- 验证：新增单测（小 MLP ckpt 保存→CLI 加载往返）+ CLI smoke 用真实 runs/ checkpoint 跑一局
  auto；`uv run pre-commit run --all-files`。

**F2. 补齐 league 配置策略调查（Q2 核心，分 5 步，最大工作块）**
1. 配置接线：`LeagueMix` 权重、promo 阈值×2、league_exploiter_share、promo_window、
   reset_mode 接进 `ExperimentConfig`/YAML（未知键已有 TypeError 保障）；删除或启用死字段
   `exploiter_keep`。

   协议对齐复现配置（MLP、env-step 口径）。
3. tools 汇总管线支持 league glob（summarize_reproduce.py / compare_with_paper.py 参数化模式）。
4. 跑 A/B：kuhn + oshi_zumo × {mirror, league} × 4–8 seeds（GPU，D6）；产物进
   `runs/league_probe/`；产出 exploitability 收敛对比曲线。
5. 写 `docs/league_investigation.md`：配置策略对比（默认 50/30/20 vs 至少一组变体，如
   history 权重加大）+ 对收敛影响的结论，回填 README 研究问题。

### P1 — 高

**F3. TTT renderer 平面语义修复**：按 OpenSpiel 实际语义（plane0=empty、X=plane2）重写渲染；

**F6. 裸默认路径 warn-loud（Q1 收尾）**：`train.py` 不带 `--config` 时打印醒目警告"当前为
NN-tuned 矩阵默认，非论文复现配置；复现请用 `configs/exp/*_ach_mlp_mirror.yaml` 或
`reproduce_paper.py`"。不改默认值本身（保护 2×2 矩阵实验），也不做静默切换（§11 禁静默
fallback）。

**F8. replay/quit 循环**：实现 docstring 已承诺的赛后 replay/quit 菜单（或删承诺；建议实现）。
**F9. `configs/games` 未知键报错**（game_config.py:55，对齐 §9）。
**F10. checkpoint 池与 §8 对齐**：二选一——给 CheckpointStore 加 TTL/weak-ref，或经评审修订

**F11. rich 美化**：兑现 pyproject 注释承诺——菜单面板、policy 表格、棋盘上色、清屏与分隔线；
菜单 blurb 截断为单行摘要（details 进 help 子项）。注意 renderer 接口不变、单测同步更新。
**F12. kuhn 动作名修正**：去掉动作 1 的误导性 "(fold)" 标注。
**F13. 加载提示**：`require_cpu()` 时打印一行说明（非静默）。
