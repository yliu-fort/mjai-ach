# Kuhn 的自由参数（α 家族）：ACH 的理论与实践如何处理

> 问题：二人零和 Kuhn poker 的纳什均衡策略有自由参数，当前 ach-mlp 理论/实践如何处理？
>
> **答案：理论上不需要处理（定理界的是集合，不是点）；实践上仓库是"隐式回避"——
> 主指标 exploitability 对家族内位置完全免疫，所以自由参数从未成为问题。代价是
> 三件已实测的事：**
> 1. **没有任何机制选择 α。** 自由方向上没有回复力，α 在训练中随机游走
>    （RL run 在 [0.155, 0.301] 内游走，sd 0.033，无系统漂移）；在**完全无噪声的
>    精确动力学**里同样不收敛（[0.207, 0.258]）——这是流形的性质，不是噪声的性质。
> 2. **熵正则不是选择器。** 一度合理的猜测（β 打破简并并设下偏置地板）**被证伪**：
>    logit 空间的熵梯度在均匀策略处**恰好为 0**，锐化后也只有 ~2e-3，比优势项低
>    1.5–2.5 个数量级。副产品：这从机制上解释了 `liars_floor_ablation.md` Phase A
>    的 β-不变性。
> 3. **一处可修的度量缺陷。** 把某个成员（α=1/3）当作"the Nash"量距离，平均把真实的
>    "到 NE 集合"距离**高估 2.46 倍**（最大 5.0 倍）。`docs/kuhn_tie_rootcause.md`
>    §1.3 正是这么做的。
>
> 附带一个精确结论：**Kuhn 的 NE 集合在行为坐标下不是一条线段**——在端点 α=1/3 处
> P0 的 `2pb` 行自身 reach 归零，多出一个自由维度（§1.3）。
>
> 度量单位：全文 exploitability = NashConv/2（仓库/论文口径，见 memory
> `exploitability-vs-nashconv-units`）。Theorem 1 的陈述引自 `docs/paper_spec_ach.md`
> §1.1 的转录（`docs/ach_paper.pdf` 不在工作区，本次未联网复核，用户裁定）。

## 1. 事实层：NE 集合的确切形状

### 1.1 家族

12 个信息态里只有 **3 个**随 α 变化，且全在 P0 一侧：

| 信息态 | 含义 | Nash 值 |
|---|---|---|
| `0` | P0 开局持 J 下注 | **α** |
| `2` | P0 开局持 K 下注 | **3α** |
| `1pb` | P0 持 Q 过牌后面对下注跟注 | **α + 1/3** |
| `1` | P0 开局持 Q 下注 | 0 |
| `0pb` / `2pb` | P0 持 J / K 过牌后面对下注跟注 | 0 / 1 |
| `0b` / `1b` / `2b` | P1 面对下注跟注（J/Q/K） | 0 / 1/3 / 1 |
| `0p` / `1p` / `2p` | P1 在对方过牌后下注（J/Q/K） | 1/3 / 0 / 1 |

**P1 一侧完全唯一。** α 的取值范围由单纯形给出：3α ≤ 1 ⟹ α ∈ [0, 1/3]。

### 1.2 float64 精确验证

`tools/kuhn_free_param.py:verify_family` 在 21 个 α 上求精确 NashConv：

```
max |NashConv| over alpha in [0, 1/3] = 5.551e-17
```

即家族**每一个成员都是精确的 Nash**，到机器精度。α = 0.4 时 3α = 1.2 越出单纯形，
`mjai.seqform` 的校验器按 AGENTS.md D15 抛 `InvalidBehaviorError`；D15 记录的
OpenSpiel 在同一策略上静默返回 −6.7e-2 的行为，本次独立复现了这个对照。

### 1.3 端点 α=1/3 处 NE 集合多一个维度（新结论）

逐行扰动 ±0.05 后对 α 取 min（`tools/kuhn_free_param.py` 附带的探针）：除 `2pb`
外每一行被扰动都使 min NashConv **严格为正**（0.0028–0.1417），即被钉死。唯独：

| α | `2pb` 设为 0.95 | NashConv | 该行的**自身** reach |
|---|---|---|---|
| 0 | 0.95 | 0.025000 | 1.0000 |
| 1/6 | 0.95 | 0.012500 | 0.5000 |
| **1/3** | 0.95 | **0.000000** | **0.0000** |

机制：α=1/3 时 3α=1，P0 持 K 必下注，"持 K 过牌"这条**自身序列**的实现概率归零，
该信息态上做什么都不影响任何人的收益。

**自由来自"自身 reach = 0"，不是"联合 reach = 0"。** 对照 P1 的 `0b`：α=0 时 P0
从不下注，该信息态在当前 profile 下不可达，但扰动它仍使 NashConv = 0.008333 ——
因为 P0 **可以偏离**去到那里，exploitability 度量的正是偏离。这条原则
`src/mjai/eval/average_policy.py` 的 docstring 已明确写出（"'the opponent never
bets' does not make a row unreached, while 'I never pass' does"），本次是对它的
独立数值确认，并定位到它在 Kuhn 上唯一发作的地方。

推论：**行为坐标下的"到 NE 集合距离"在该面上是病态的**（任何值都合法）。序列形式
（实现计划）坐标下 NE 集合是凸多面体，这个面就是那个多出来的维度——这也是仓库
在序列形式下做平均（D16）在数学上正确的另一个理由。

## 2. 理论层：ACH 为什么不需要处理自由参数

Theorem 1（`paper_spec_ach.md` §1.1）界的是**平均策略的 exploitability**
`ε ≤ |S|Δ√(ln|A|/(2T)) + Δ Σ_s (w_h−w_l)/w_h`。这是一个关于**到 NE 集合的距离**的
陈述，不是关于收敛到某个点的陈述。所以：

- 自由参数在定理层面**不构成问题**：exploitability 对家族内的位置恒为 0，界照常成立。
- 但定理也**不承诺** α 稳定。沿家族方向 exploitability 精确平坦 ⟹ 该方向没有梯度
  信号 ⟹ 最后一轮迭代不作为"点"收敛。仓库所有曲线记的都是**当前策略**
  （`reproduce_report.md`），因此这一点直接影响 last-iterate 研究的解读。

## 3. 实践层：仓库当前如何处理

| 位置 | 处理方式 | 判定 |
|---|---|---|
| `eval/nash.py`、`seqform/plan.py` 的主指标 | exploitability / NashConv，对选哪个 NE 天然不变 | **正确**（这就是"隐式回避"） |
| `eval/average_policy.py`（D16） | 在**实现计划**坐标下平均；2p0s 的 NE 集合在该坐标下是凸的，NE 的平均仍是 NE | **正确**（但 Kuhn 上测不出差别，见 §3.1） |
| `mjai.atlas`（D12 计划存放"symbolic 2p Kuhn alpha-family"） | **目前是空壳**，只有 `__init__.py` | 计划中，未实现 |
| `docs/kuhn_tie_rootcause.md` §1.3 的 "L1-to-Nash (α=1/3)" | 把单个成员当作"the Nash" | **病态度量**，见 §4.3 |

### 3.1 两种平均在 Kuhn 上差别不可测（诚实报告）

对同一条轨迹的 100 个 checkpoint 分别做逐信息态行为概率平均与实现计划平均：

| 平均方式 | exploitability |
|---|---|
| 朴素行为概率平均 | 0.012119 |
| 实现计划平均（CFR 的平均策略） | 0.012018 |

两者平均绝对差 2e-4。**Kuhn 的树太浅**（P0 自身序列深度 ≤ 2），reach 加权几乎不起
作用，所以这个理论上重要的区分在 Kuhn 上**测不出来**——不能拿 Kuhn 作为该设计决策的
证据。（交叉验证：实现计划平均 0.01202 与 `average_policy_anchor.md` 记录的 Kuhn
uniform 平均 0.0123 一致，口径与实现无误。）

## 4. 实测：训练中 α 到底在做什么

数据源 `runs/avg_anchor/kuhn_seed0`（论文忠实 mirror 臂 + D16 追踪器，1e7 env-steps
= 154476 次更新，100 个 checkpoint），逐 checkpoint 分解，取后半段 50 点统计。

### 4.1 exploitability 只看"离开家族"的分量

| 相关系数（后半段 n=50） | 值 |
|---|---|
| corr(expl, **离家族**距离) | **+0.798** |
| corr(expl, P1 侧误差) | +0.658 |
| corr(expl, **α̂**) | **+0.096** |
| corr(expl, \|α̂ − 1/6\|) | +0.085 |

且 expl ≈ **1.26 ×** 离家族平均绝对偏差。

**判定：exploitability 由离家族分量解释，对策略在家族上的位置几乎完全失明**——
这正是理论预言的形状，实测确认。

### 4.2 α 不收敛（有噪声、无噪声都不收敛）

| 轨迹 | α̂ 均值 | sd | 范围 |
|---|---|---|---|
| RL run（MLP + 采样，后半段） | 0.2126 | 0.0327 | [0.155, 0.301] |
| **精确动力学**（表格、无采样噪声、精确优势，后半段） | 0.2331 | 0.0155 | [0.207, 0.258] |

RL 轨迹的逐点增量：均值 −0.0011，sd 0.0449 ⟹ **无可检测的系统漂移**（|均值| 远小于
2×标准误）。三个独立读数（由 `bet(J)`、`bet(K)/3`、`call(Q)−1/3` 各读一次 α）的
平均离散度 0.1097 ⟹ 策略也并未精确落在家族上。

**判定：自由方向上没有回复力。** 噪声会放大游走幅度（sd 0.033 vs 0.016），但**不是
成因**——无噪声的精确动力学同样不收敛到点。

### 4.3 "到 α=1/3 的距离"高估了误差

| 度量 | 后半段均值比 |
|---|---|
| d(α=1/3) / d(NE **集合**) | **2.46×**（最大 **5.0×**） |

即 `kuhn_tie_rootcause.md` §1.3 报告的 "L1-to-Nash" 把"沿家族移动"（免费、无害）和
"离开家族"（真实误差）混在一起，系统性地把误差放大约 2.5 倍。正确做法是对 α 取
min（`tools/kuhn_free_param.py:distance_to_family`）。

> 注：这**不改变** `kuhn_tie_rootcause.md` 的结论。该报告用这个距离说明"两臂训练后
> 都比随机初始化离 Nash 更远"（0.389 → 0.41–0.51），而随机初始化的基线用的是同一个
> 病态度量，方向性比较仍然成立。修正只影响绝对值的解读。

## 5. 谁选择了 α？没有人——熵正则被证伪

一个自然的假设：β=1e-2 的熵正则把不动点从 NE 集合推到唯一的（熵正则化）均衡，
于是 β 悄悄定死了 α，代价是一个偏置地板。**这个假设被证伪，且有机制。**

ACH 损失里熵项是 `β Σ_b π_b log π_b`，对 **logit** `y_j` 的梯度是

```
∂/∂y_j [ β Σ_b π_b log π_b ] = β · π_j · ( log π_j + H(π) )
```

- 在**均匀策略**处 `log π_j = −ln n`、`H = ln n` ⟹ 括号**恰好为 0**，熵项梯度精确消失。
- 锐化到 π=(0.9, 0.1) 时也只有 `1e-2 × 0.9 × 0.2197 ≈ 2.0e-3`。
- 对照 ACH 的策略项 `η · A`（η=1，A 的量级 O(0.1–1)）：**低 1.5–2.5 个数量级**。

精确动力学的逐点对照（Kuhn，156k 次更新，`paper` vs `beta0`）：

| iter | β=1e-2 | β=0 |
|---|---|---|
| 26000 | 0.105114 | 0.105491 |
| 52000 | 0.125509 | 0.127629 |
| 104000 | 0.057524 | 0.058176 |
| 156000 | 0.067710 | 0.070559 |

两条曲线**逐点重合**。

**副产品**：这解释了 `liars_floor_ablation.md` Phase A 观察到但未给机制的现象——
liars 的 β-sweep（1e-2 → 0）地板纹丝不动，正是因为熵项在 logit 空间的梯度比优势项
低两个数量级。β **不是杠杆，不是因为它的作用被别的因素掩盖，而是因为它本来就几乎
不产生梯度。**

## 6. 结论与建议（不动默认，AGENTS.md 先例）

1. **理论上无需处理**：ACH 的保证是到 NE 集合的距离，自由参数不影响任何界。
2. **实践上"隐式回避"是正确的默认**：主指标免疫，平均策略在正确的坐标系下做。
   **不建议**为 Kuhn 引入"选择某个 α"的机制——那既无理论依据，也会污染论文复现。
3. **建议修的一处**：任何"到 Nash 的距离"必须是到 **NE 集合**的距离（对 α 取 min），
   不是到某个成员的距离。当前只在 `docs/kuhn_tie_rootcause.md` §1.3 出现，**未泄漏
   进任何已提交的 `src/` 或 eval 路径**（已 grep 确认：committed 代码里唯一的
   "到解析 Nash 的距离"是 `eval/nash.py:distance_to_brps_nash`，而 BRPS 的 NE
   (1/16, 10/16, 5/16) 是**唯一**的，该度量良定义）。本次把正确实现放在
   `tools/kuhn_free_param.py`，不进 `eval/`（进 eval 即公共模块，按 §5 需单测 +
   注册进 eval config，收益不足以支付）。
4. **last-iterate 解读要加一句限定**：Kuhn 当前策略曲线的末段抖动里，有一部分是沿
   NE 家族的无害游走，不是收敛失败。要分离，用 §4.1 的离家族分解。
5. **`mjai.atlas` 落地时**（D12/pACH Step-0）应把 §1.1 的家族表 + §1.3 的端点额外
   维度一起写进 `atlas.json`——后者是本次新发现的，不写会让"3p Kuhn 的局部维度 m*"
   那套刻画在 2p 基准上就不自洽。
