# ACH 算子的不动点结构：为什么 logit 门控给出一个训练不掉的地板

> **一句话结论**：ACH 收敛到 Nash 的**唯一途径**是让 logit 跑到 ±∞——这不是病态，这正是 Hedge
> 在做的事（`y` 追踪的是**累积** regret）。**单边 logit 门控在构造上禁止了这件事**。于是被门控的
> 算子**到不了任何非全混合的 Nash**，其残余 exploitability 就是盒子强行漏给劣势动作的那部分
> 概率质量，闭式为
>
> ```
> leak(s) = (n - k) / (k · e^{2·l_th} + (n - k))      # n = 合法动作数，k = 支撑大小
> ```
>
> 这条正是 `docs/liars_operator_floor.md` §8 局限 4 列为"**剩下的嫌疑，未直接测**"的那一条。
> 本文给它方程，用 sympy 逐步验证（28/28 PASS），在一个有闭式解的玩具上把动力学**逐位**验证到
> 4 位有效数字，然后在 liar's dice 上测出**定量闭环**：
>
> **`l_th=2` 时盒子内的最优 exploitability 是 0.1030，动力学地板是 0.0990——在优化器余量内
> 完全一致。ACH 在 liar's dice 上不是"没收敛"，它收敛到了它的门控允许的最好策略。**
>
> | 层级 | 命题 | 证据 |
> |---|---|---|
> | 恒等式 | 熵梯度的动作和 ≡ 0；`Σ_a A_a` 无权和在部分混合均衡处 < 0 | sympy V3–V6 |
> | 结构 | 无门控 ACH 在 `y` 与 `π` 两个空间里**都没有不动点** | sympy V7 + 玩具（eps → 1.1e-16，分离度线性发散到 2000） |
> | 闭式 | 门控的不变盒子 ⇒ `leak = (n−k)/(k e^{2l_th} + (n−k))` | sympy V8/V8b + 玩具 4 位吻合 |
> | **实测** | **地板确实坐在盒子壁上**：ρ 最高十分位分离度中位数 **4.0025 = 2·l_th** | §10.1（N3） |
> | **实测** | **地板 = 盒子内最优**：0.1030 vs 0.0990 | §10.2（N1） |
> | **实测** | **`l_th` 扫描贴合盒子界**：1→0.44、2→0.0985、3→0.0214 | §10.4（N4） |
> | 更正 | centered 门控是**更松**的那一个；但 liar's dice 上差别很小，因为多数行只有 2 个合法动作 | 玩具 + §10.3（N2） |
>
> 度量单位：exploitability = NashConv/2（`exploitability-vs-nashconv-units`）。
> 论文取用方式见 `docs/paper_spec_ach.md`。

## 0. 研究对象与它为什么是对的对象

本文推导的是 `tools/exact_ach.py` 迭代的**期望算子**：

```
y_{t+1}(s,a) = y_t(s,a) + λ · w_t(s) · [ η · c_t(s,a) · A_t(s,a)
                                        − β · π_t(a|s) · (log π_t(a|s) + H_t(s)) ]
```

不是 RL 管线。理由：地板在精确算子里是 **0.0990**，在 RL 里是 0.146；把噪声、函数逼近、
批量全部拿掉之后它还在，所以根因必须在这个确定性映射的**不动点结构**里。
0.099 → 0.146 那一段（MLP + 采样）已有归因（`docs/liars_floor_ablation.md`、
`docs/liars_machine_precision.md`），**本文不碰**。

`w_t(s)`（到达概率权重）在本文中**几乎不出现**——这不是疏漏，而是结论：
`docs/liars_operator_floor.md` §5 已经用形状配平的冻结臂证明权重的时间漂移
**对本算子的地板没有可测影响**（0.0992 vs 0.0985）。本文找到的机制与 `w` 完全无关，
这与那个实测**一致**。

## 1. 期望梯度：`1/π_old` 精确抵消（V1）

论文 Eq. 29 的逐样本损失是 `−c·η·y(a)/π_old(a)·A(a)`（p24）。对 logit `y_j` 求导只在被采样
的那个动作上非零；对 `a ~ π` 取期望，且同步单线程下 `π_old = π`（p28）：

```
E_{a~π}[ ∂/∂y_j ( −c_a · η · y_a / π_old(a) · A_a ) ] = −η · c_j · A_j
```

**那个会在稀有动作上炸掉的 `1/π_old`，与采样概率精确抵消。** 这是 `tools/exact_ach.py`
整个工具的合法性前提，它的 docstring 此前只是断言，从未验证。现在验证了（V1）。

**推论（V2）**：若把损失体换成减均值的 `y_a − ȳ`（`loss_centered_logits=True`），期望梯度变成
`−η(c_j A_j − mean_b c_b A_b)`，**动作和恒为 0**。所以下面第 3 节那个规范漂移是**原始（raw）
损失体**的性质——而 raw 正是仓库默认（`nn_losses.py` 的 `loss_centered_logits=False`）。

## 2. 熵项在规范方向上是零（V3/V4）

```
∂/∂y_j [ β Σ_b π_b log π_b ] = β · π_j · (log π_j + H)
Σ_j 的结果 ≡ 0
```

第二行是承重的：**熵正则在规范方向 `1` 上没有任何分量**，它只能挪策略，**永远挪不动 logit
的均值**。所以它无法为下一节的漂移提供任何制动。

## 3. 规范方向的漂移，及其在部分混合均衡处的符号（V5/V6）

`softmax(y + k·1) = softmax(y)`：**logit 均值在策略空间里不可观测**，是一个自由方向（V5）。

而算子在这个方向上有净漂移：

```
Σ_j Δy_j = λ · w · η · Σ_a c_a A_a          （熵项贡献 0，由 V4）
```

关键在于 `Σ_a A_a` 与 `Σ_a π_a A_a` 是**两个不同的和**。后者恒为 0（`V` 就是均值，V6），
但那是 **π 加权**的，对无权和什么也没说：

```
Σ_a A_a = Σ_a Q_a − n·V
```

在**部分混合**均衡处，支撑内 `A_a = 0`、支撑外 `A_a < 0`，故 `Σ_a A_a < 0` **严格成立**（V6）。
⇒ **即使策略已经收敛，整条 logit 向量仍在匀速下沉。**

> **全混合均衡是退化情形**：那里所有 `A_a = 0`，无权和也是 0，没有漂移。标准 RPS、BRPS
> 都属于此类，用它们做验证会什么也看不见。这是下面玩具刻意加一个**劣势动作**的原因。

## 4. 无门控 ACH 根本没有不动点（V7）

玩具：RPS + 一个严格劣势动作 X（对谁都输）。唯一 Nash 是 `{R,P,S}` 上均匀、X 为 0
——**部分混合**，正是第 3 节说的那个情形。在对称轴 `π = (p,p,p,q)` 上，sympy 给出**恒等式**

```
A_R − A_X ≡ 1          （与 p 无关！）
```

策略不动点要求逐动作更新量跨动作相等（纯规范移动不改 π），在对称轴上退化成一个标量方程，
其 η 部分恒为 `η·1`，于是条件成为

```
η = β · [有界量]
```

实测该有界量 `|bracket|/β ≤ 0.550`。论文取 `η = 1`、`β = 1e-2` ⇒ **方程无解**。

**所以无门控 ACH 在 `y` 空间和 `π` 空间里都没有不动点**：`y_R − y_X` 无界增长，
`y_X → −∞` 是它收敛到 Nash 的**唯一**方式。

**这不是缺陷，这就是 Hedge。** 定理 1 要的就是 `y ≈ R^a_t`（**累积**加权 regret），
而累积量本来就该无界。

## 5. 门控的不变盒子，与它强行漏出的质量（V8/V8b）

论文的门控（Algorithm 2, p24）是**单边、优势符号依赖**的：`A ≥ 0` 的动作升不过 `+l_th`，
`A < 0` 的降不过 `−l_th`。熵项虽不受门控，但它始终指向均匀，即**向内**。所以只要一个动作的
优势符号是持久的，它的 logit 就被困在 `[−l_th, l_th]`（差一步）。

**静止要求两侧的门都关上**：先关的那一侧只是停止贡献，另一侧会继续拉开分离度。于是

```
sep_raw = 2 · l_th
```

设 `k` 个支撑内动作停在 `+l_th`、`n−k` 个支撑外动作停在 `−l_th`，则漏出的总质量

```
leak = (n−k)·e^{−l_th} / (k·e^{+l_th} + (n−k)·e^{−l_th})
     = (n−k) / (k·e^{2·l_th} + (n−k))
```

> **`k` 是关键，初版手推漏掉了它。** 用 `1/((n−1)e^{2l}+1)` 会把支撑大的情形当成一般情形，
> 在 liar's dice 上低估两个数量级（0.0015 vs 0.09–0.18）。

`l_th = 2` 时的数值：

| n | k | 漏出质量（raw） |
|---|---|---|
| 4 | 3 | 0.00607 |
| 13 | 6 | 0.0209 |
| 13 | 2 | **0.0915** |
| 13 | 1 | **0.180** |

## 6. raw 与 centered 门控：**centered 是更松的那一个**（V9）

`k` 高 `n−k` 低的构型下，`u − ȳ = (n−k)(u−v)/n`、`ȳ − v = k(u−v)/n`。两侧的门都关上要求

```
sep_centered = n · l_th / min(k, n−k)   ≥   2·l_th = sep_raw
```

等号仅在支撑恰占一半时成立。**所以论文正文那个减均值门控（`paper_spec_ach.md` 歧义 A3）
比仓库的 raw 门控更松**；而仓库选 raw 是因为它复现出了论文的 Liar's Dice 曲线
（`docs/reproduce_report.md` §6.5）。**造成地板的正是这个选择。**

> **这是一处更正。** 初版手推取"**先**关闭"的那一侧作约束，得到 `n/(n−1)`，据此预言 centered
> 更差。`tools/ach_theory_toy.py` 直接证伪：玩具的 centered `l_th=1` 停在分离度 **4.000**，
> 不是 4/3。更正后方向相反且预言更强。

`tools/ach_theory_toy.py`，`η=1, β=1e-2, lr=1e-3`（论文值），单信息态（`w(s)=1` 因而退出，
刻意隔离掉 `liars_operator_floor.md` 已经解决的所有权重问题），2×10⁶ 步：

|---|---|---|---|---|---|
| **无门控** | **1.110e-16** | → 0 | **1999.996** | **−499.712** | 0.000 |
| raw `l_th=1` | 4.313e-02 | 4.316e-02 | 2.001 | 0.500 | 1.000 |
| raw `l_th=2` | 6.066e-03 | 6.068e-03 | 4.000 | 1.000 | 1.000 |
| raw `l_th=3` | 8.248e-04 | 8.256e-04 | 6.001 | 1.500 | 1.000 |
| centered `l_th=1` | 6.068e-03 | 6.068e-03 | 4.000 | 2.385 | 1.000 |
| centered `l_th=2` | 5.290e-04 | 1.118e-04 | 6.445 | 2.614 | 0.250 |
| raw `l_th=2`, n=6 | 1.797e-02 | 1.799e-02 | 4.001 | −0.000 | 1.000 |
| raw `l_th=2`, n=13 | 5.753e-02 | 5.754e-02 | 4.000 | −1.077 | 1.000 |

**无门控那一行是整件事的正面证据**：它收敛到**机器精度的精确 Nash**（1.1e-16），
代价是分离度线性发散到 1999.996 —— 等于 `lr·η·(A_R−A_X)·T = 1e-3 × 1 × 2e6`，
**第 4 节那个恒等式 `≡1` 精确兑现**；同时 `ȳ` 沉到 −499.712 —— 等于
`lr·η·(Σ_a A_a)/n·T = 1e-3 × (−1/4) × 2e6`，**第 3 节那个漂移率精确兑现**。
**两个发散率都是推出来的，不是拟合的。**

加上门控后分离度**精确**停在 `2·l_th`，`gate_off_frac = 1.000`（所有坐标贴墙），
eps 与闭式解 4 位吻合，且随 `n` 增长而增长。

centered 的 `l_th ≥ 2` 两行未到角点（`gate_off = 0.250`，只有劣势动作被挡），仍在缓慢下行——
即第 6 节说的"更松，以至于在预算内根本不触壁"。

|---|---|

## 9. 两个体制：盒子约束 vs 无盒子的循环

玩具里**无门控 → 精确 Nash**；但 liar's dice 上**无门控是 0.37–0.40**，**`l_th=8` 是 0.25
且单调上升**（`liars_operator_floor.md` §5.1、§8.11）。方向相反。

原因：玩具的劣势动作是**无条件**劣的，因此不会循环；而树形零和博弈里无正则的 logit 空间 PG
**是会循环**的（NeuRD / replicator 那一类的已知行为）。所以 liar's dice 上有**两个**体制：

- **`l_th` 小 → 盒子约束体制**：盒子偏置就是地板，训练多久都消不掉；
- **`l_th` 大 → 循环体制**：盒子不再是约束，但去掉它也换不来收敛。

第 10 节的 N4 把两个体制的**分界**测了出来：`l_th ≤ 3` 属于前者（地板贴着盒子界），
`l_th ≥ 8` 属于后者。**论文取的 `l_th = 2` 稳稳落在盒子约束体制里。**

### 10.1 N3：地板确实坐在盒子壁上

`tools/gate_box_probe.py`，读 `M_liars_rho0.5_policy.pt`（`rho:0.5` 的 39k 终点，expl 0.099033）。
分离度 = `log π_max − log π_min`（逐行、仅合法动作）；softmax 的平移不变性（V5）保证它**精确等于**
`y_max − y_min`，因此从 behaviour 包里可以无损恢复。

| ρ 十分位 | ρ 中位数 | 分离度中位数 | p90 | `|sep−4|<0.1` 的比例 | n 中位数 |
|---|---|---|---|---|---|
| 0–4 | 5.8e-11 … 1.6e-08 | **0.0000** | 0.88–3.16 | 0.000 | 1 |
| 5 | 4.7e-08 | 0.2254 | 3.44 | 0.007 | 2 |
| 6 | 1.4e-07 | 2.4575 | 3.81 | 0.072 | 2 |
| 7 | 4.9e-07 | 3.1362 | 4.0005 | 0.240 | 2 |
| 8 | 3.5e-06 | **4.0000** | 4.0017 | 0.523 | 2 |
| **9** | **6.9e-05** | **4.0025** | 4.0158 | **0.696** | 4 |

**ρ 加权平均分离度 = 3.9419。** 最高的两个十分位的分离度中位数是 **4.0000 / 4.0025**——
`2·l_th` 精确到 3–4 位小数，且随 ρ 单调逼近。低 ρ 行分离度是 0，因为它们几乎没动过。

> **这同时给了 `floor_microscope` 那个 95.3% 一个机制**：地板集中在 ρ 最高的十分位，
> **正因为那些行是唯一走到壁上的行**。

**壁随 `l_th` 移动——第二个独立确认。** 对 N4 的 `l_th=3` 终点策略跑同一个探针：
最高十分位分离度中位数 **5.9376**，目标 `2·l_th = 6.0`，`|sep−6|<0.1` 的比例 0.502，
ρ 加权平均分离度 5.7768。**换一个阈值，壁就换一个位置，且位置恰好是 `2·l_th`。**

### 10.2 N1：地板 = 盒子里能达到的最优值

`tools/box_bound.py`：在约束集 `y ∈ [−l_th, l_th]` 上直接极小化 exploitability
（投影梯度，Adam，8000 步，float64）。这条**完全不引用动力学**。

| `l_th` | 盒子内最优（本优化器所得） | 最大分离度 |
|---|---|---|
| 1 | 0.359631 | 2.0000 |
| **2** | **0.102961** | 4.0000 |
| 3 | 0.024790 | 6.0000 |
| 4 | 0.005445 | 8.0000 |
| ∞ | 0.001631 | 15.94 |

**`l_th=2` 的盒子最优 0.1030，动力学地板 0.0990。**

注意方向：这个优化器给的是盒子最优的**上界**（非凸局部搜索），所以真实盒子最优 ≤ 0.0990。
**二者在优化器自身的余量（~4%）内一致。** 结论因此是最强的那种：

> **ACH 在 liar's dice 上不是"没收敛"。它收敛了——收敛到它的门控允许的最好策略。**

`l_th=∞` 那一行（0.0016 vs 真实 Nash 1.27e-4）是优化器余量的独立标定。

### 10.3 N2：centered 门控——方向对，幅度小，且幅度被解释

`--gate-centered` 跑 80k：**final expl 0.096319**，对照 raw 的 0.0985。方向与更正后的理论
一致（centered 更松 ⇒ 地板略低），但幅度远小于 V9 对 `n=13` 的预期。

**幅度小的原因是可测的**：对 centered 的终点策略跑同一个探针，ρ 加权平均分离度 **4.6636**
（raw 是 3.9419），最高十分位分离度中位数 **4.0028**、p90 **4.0966**——确实略微越过了 4，
但没有 V9 对 `n=4,k=1` 预言的 8。**因为 liar's dice 的活跃行 `n` 中位数只有 2–3**：
`n=2` 时 `sep_centered = 2·l_th/min(1,1) = 4 = sep_raw`，**两种门控完全重合**。

> 所以 V9 的公式在这里给出的预言是"**几乎没有差别**"，实测 0.0963 vs 0.0985 正是如此。
> 第 5 节表里 `n=13` 那几行**不适用于 liar's dice 的多数信息态**——那是本文最初的量级估计
> 用错了 `n` 的地方。

**`tools/box_bound.py` 刻意不提供 centered 模式**：`{y : |y−ȳ| ≤ l_th}` 是比 raw 盒子**更小**的
集合（`n=3`、logits `(0,0,−2l_th)` 分离度合法但偏差 `4l_th/3` 超限），而 centered 门控的实际
静止集比 raw **更大**——硬对称盒子在两个方向上都不是它的正确模型。此处以实测分离度为准。

### 10.4 N4：两个体制的分界

| `l_th` | 盒子界（N1） | 动力学地板 | 比值 | 体制 |
|---|---|---|---|---|
| 1 | 0.3596 | **0.4413**（60k，20k 起持平） | 1.23 | 盒子约束 |
| **2** | **0.1030** | **0.0985** | **0.96** | 盒子约束 |
| 3 | 0.0248 | **0.0214**（60k，仍缓降） | 0.86 | 盒子约束 |
| 8 | ≈ 0 | 0.25 且**上升**（§5.1） | — | 循环 |
| ∞ | 0.0016 | 0.37–0.40（§8.11） | — | 循环 |

`l_th ∈ {1,2,3}` 三点上动力学地板与盒子界在 **±25% 内**贴合并**同向单调**；`l_th ≥ 8` 脱钩。

> **这更正了 `liars_operator_floor.md` §5.1 的一个读法。** 那里由 `l_th=8` 更差推出
> "门控是必要稳定器，不是可以放松的负担"。**前半句对，后半句过强**：`l_th=3` 把地板从
> 0.0985 降到 **0.0214（4.6×）**，只是 `l_th=8` 已经越过了分界。**§5.1 从未测过 3。**

## 13. 局限

1. **循环体制未推导**（第 9 节）。只推了盒子偏置；`l_th ≥ 8` 那一侧仍是描述性的。
2. **盒子界是上界不是下界**。`tools/box_bound.py` 是非凸局部搜索，给的是盒子最优的**上界**。
   所以 §10.2 只能宣称"在优化器余量内一致"，不能宣称精确相等。`l_th=∞` 那一行（0.0016 vs
   1.27e-4）是这个余量的标定。
3. **N4 的 `l_th=3` 未跑到收敛**（60k 时 0.0214 仍在缓降），`l_th=1` 已持平（20k–60k 无趋势）。
4. **只在 `weighting=rho:0.5` 这一个体制上做**。换权重（`reach`、`uniform`）的地板归因未测。
5. **玩具是单信息态矩阵博弈**，且其支撑内动作优势符号持久。树上若某行优势符号在迭代之间翻转，
   "贴壁"论证需要重述——N3 的分离度稳定饱和是间接证据，不是直接检验。
6. **未回到 RL 管线**。0.099（精确算子）→ 0.146（MLP + 采样）那一段仍归既有报告，本文的盒子
   机制是否在 MLP 上以同样形式成立**未测**（MLP 的 logit 不是自由参数，LayerNorm 还额外约束了
   尺度——见 `nn_losses.py` 关于 A3 的注释）。
